KJ PROPERTY HUNTER — HOTEL EDITORIAL V3

แนวทางดีไซน์
- Minimal luxury / boutique hotel / private residence
- ไทย + อังกฤษ
- Ivory / stone / charcoal / warm beige
- Editorial serif typography
- ลดกล่อง ลดความเป็น dashboard-style ในเว็บลูกค้า
- Hero เต็มจอ ใช้ภาพห้องแรกจาก public_property_images อัตโนมัติ
- Responsive มือถือ

วิธีใช้
1. สำรองโปรเจกต์เดิม
2. คัดลอกโฟลเดอร์ app, lib, supabase จากชุดนี้ไปวางทับโปรเจกต์เดิม
3. อย่าลบ .env.local
4. npm install
5. npm run dev
6. ตรวจ http://localhost:3000 และ /admin/login
7. npm run build ก่อน deploy
